# 🏐 Montador de Times VG

Um aplicativo web simples e intuitivo para organizar times de voleibol de forma equilibrada e sem discussão!

## 📱 Acesso Rápido

[Clique aqui para usar o app](https://mayfriend.github.io/volleyball-app/)

## ✨ O que é?

O **Montador de Times VG** é uma ferramenta que ajuda a organizar times de vôlei de forma justa e equilibrada. Você marca quem vai jogar, escolhe a estratégia de organização e o app faz todo o trabalho de distribuir as jogadoras entre os times.

## 🎯 Como Funciona?

1. **Selecione as jogadoras** que vão participar
2. **Escolha uma estratégia** de montagem
3. **Veja os times prontos** com a distribuição equilibrada

## 🎲 As 3 Estratégias

### 🔄 **Rodízio**
Distribui as jogadoras alternando entre os times da melhor para a pior.
- Cada time recebe um "mix" equilibrado de habilidades
- Bom para jogos casuais

### ⚖️ **Soma Equilibrada**
Calcula o total de pontos (ataque + levantamento + passe) e distribui para deixar os times com totais parecidos.
- A forma mais "justa" e equilibrada
- Perfeito quando quer competição de verdade

### 🏐 **Balanceamento por Posição**
Primeiro garante que cada time tem uma boa levantadora, depois equilibra o resto.
- Respeita a importância de cada posição
- Melhor quando a levantadora é a chave do time

## 📊 Sistema de Notas

Cada jogadora tem 3 notas (1-5):
- **Ataque** - Força no ataque
- **Levantamento** - Qualidade da levantada
- **Passe** - Recepção e passe
